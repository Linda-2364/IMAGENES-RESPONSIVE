Ejercicio 5: Imágenes Responsive

Abre las herramientas de desarrollador (F12) y redimensiona la ventana para ver los cambios en las imágenes según el tamaño de pantalla.

1. Srcset y Sizes (Misma imagen, distintos tamaños)

El navegador elige automáticamente la mejor imagen basándose en el ancho de pantalla y la densidad de píxeles (DPI).

¿Cómo funciona?

srcset: Define las diferentes versiones de la imagen (400w, 800w, 1200w).

sizes: Define cómo se mostrará la imagen en diferentes breakpoints.

El navegador usa esta información para descargar solo la imagen óptima para cada situación.

Imagen responsive con srcset

Ejemplo de código:

<img srcset="imagen-400w.jpg 400w,
             imagen-800w.jpg 800w,
             imagen-1200w.jpg 1200w"
         sizes="(max-width: 600px) 100vw,
                (max-width: 900px) 50vw,
                33vw"
         src="imagen-fallback.jpg" alt="...">

2. Elemento Picture (Art Direction)

Usamos imágenes diferentes para diferentes contextos: una imagen vertical para móviles y una horizontal panorámica para escritorio.

Art Direction

No solo cambia el tamaño, sino también la composición de la imagen según el dispositivo. Esto mejora la experiencia de usuario al mostrar la imagen más apropiada para cada contexto.

Art direction con elemento <picture>

Ejemplo de código:

<picture>
  <source media="(min-width: 1024px)" 
          srcset="imagen-desktop.jpg">
  <source media="(min-width: 768px)" 
          srcset="imagen-tablet.jpg">
  <img src="imagen-mobile.jpg" alt="...">
</picture>

3. Background Image Responsive (CSS)

La imagen de fondo de este contenedor cambia mediante media queries en CSS según el tamaño de pantalla.

Código CSS

Se utilizan media queries para cambiar la imagen de fondo según el ancho de pantalla:

  • Mobile: < 600px
  • Tablet: ≥ 600px
  • Desktop: ≥ 1024px

Contenido sobre el fondo

Este fondo cambia según el tamaño de pantalla. ¡Redimensiona la ventana para verlo!

Fondo responsive con media queries CSS

Ejemplo de código CSS:

.hero-background {
  background-image: url('imagen-mobile.jpg');
}

@media (min-width: 600px) {
  .hero-background {
    background-image: url('imagen-tablet.jpg');
  }
}

@media (min-width: 1024px) {
  .hero-background {
    background-image: url('imagen-desktop.jpg');
  }
}
